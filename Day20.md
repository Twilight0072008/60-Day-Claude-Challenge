# Day 20 – AI-Powered Face Puzzle Game

## Objective

The objective of this exercise was to use Claude AI to generate a complete browser-based Face Puzzle Game. The application captures a photo using the user's webcam, converts it into a puzzle, and provides an interactive gameplay experience with multiple difficulty levels, timers, move tracking, and leaderboard functionality.

---

# Task Overview

For this challenge, I used Claude to generate a complete HTML application capable of creating a personalized sliding puzzle game from a webcam photo.

The generated application was tested in a web browser by granting camera permissions, capturing an image, selecting a puzzle difficulty, and completing the puzzle while tracking time and moves.

---

# Workflow

1. Opened Claude and started a new conversation.
2. Set the effort level to Low/Medium/High.
3. Used the provided Face Puzzle Game prompt.
4. Generated the complete HTML application.
5. Saved the HTML file locally.
6. Opened the application in a web browser.
7. Allowed webcam access.
8. Captured a personal photo.
9. Selected puzzle difficulty (3×3, 4×4, or 5×5).
10. Played the puzzle game.
11. Tested drag-and-drop and touch controls.
12. Verified timer, move counter, and leaderboard.
13. Completed the puzzle and reviewed the results.

# Key Learnings

### 1. AI Can Generate Complete Interactive Applications

Claude successfully generated a fully functional browser game using a single well-structured prompt.

---

### 2. Browser APIs Enable Rich User Experiences

Integrating webcam access and image processing demonstrates how modern browser APIs can power interactive web applications.

---

### 3. Prompt Engineering Improves Development Speed

Providing detailed requirements allowed the AI to generate a feature-rich application with minimal manual coding.

---

### 4. User Experience Matters

Features such as multiple difficulty levels, timers, move counters, animations, and responsive design significantly improve engagement.

---

### 5. AI Accelerates Rapid Prototyping

Instead of building every component manually, AI produced a working prototype that can be customized and enhanced further.

---

# Conclusion

This project showcased how AI can assist in developing interactive web applications by combining frontend technologies, browser APIs, and creative prompt engineering. The Face Puzzle Game demonstrates how personalized experiences can be created with AI while strengthening practical web development skills.

## Main Takeaway

**AI is not just a coding assistant—it can rapidly prototype complete, interactive applications that combine creativity, browser capabilities, and user engagement into real-world projects.**
