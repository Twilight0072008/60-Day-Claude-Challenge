# 🏥 Day 28 – Hospital Admission Readiness Simulator

## Overview

As part of **Day 28 of the 60 Days Claude AI Mastery Challenge**, I developed a **Hospital Admission Readiness Simulator** using Claude AI. The project simulates the complete hospital admission workflow, enabling users to evaluate admission readiness by managing documentation, insurance verification, prior authorization, clinical requirements, and operational risks.

The simulator provides an interactive environment that demonstrates how multiple healthcare departments coordinate to ensure safe and compliant patient admissions.

---

# Objectives

* Simulate the end-to-end hospital admission readiness process.
* Understand how documentation, insurance verification, and prior authorization influence admission decisions.
* Visualize healthcare operational workflows through an interactive web application.
* Learn risk assessment and governance concepts used during hospital admissions.
* Build a responsive browser-based simulator using a single HTML file.
