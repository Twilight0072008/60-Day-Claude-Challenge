# Day 6 – Claude Usage Strategy

## Objective

The objective of this exercise was to create a personalized Claude usage strategy based on my profile as a student. The goal was to understand which Claude models to use for different tasks, how to optimize effort settings, and how to maximize productivity while managing usage efficiently.

---

# Strategy Overview

### User Profile

* Student
* Occasional Claude User
* Interested in:

  * Coding
  * Research
  * Content Creation
  * Business & Marketing Ideas
  * Learning New Concepts

### Recommended Model

**Claude Sonnet**

Sonnet was identified as the most suitable model because it provides a balance between reasoning ability, response quality, speed, and usage efficiency.

---

# Model Selection Strategy

## Claude Haiku

### Best For

* Quick definitions
* Simple fact checking
* Short summaries
* Small code fixes

### Benefits

* Fast responses
* Efficient for lightweight tasks
* Conserves usage limits

---

## Claude Sonnet

### Best For

* Coding projects
* Research assignments
* Content writing
* Study assistance
* Marketing plans
* Learning complex concepts

### Benefits

* Strong reasoning capabilities
* High-quality outputs
* Suitable for most daily tasks
* Best balance between performance and efficiency

---

## Claude Opus

### Best For

* Thesis research
* Capstone projects
* Complex problem solving
* High-stakes work

### Benefits

* Deep reasoning
* Advanced analysis
* Highest quality outputs

### Limitation

Should be reserved for important tasks because it consumes more resources.

---

# Effort Level Strategy

## Low Effort

Used for:

* Quick lookups
* Definitions
* Minor edits

## Standard Effort

Used for:

* Daily learning
* Coding assignments
* Content creation
* Research summaries

Recommended for most tasks.

## High Effort

Used for:

* Technical reports
* Business strategies
* Complex coding issues
* Detailed research

## Max Effort

Used only for:

* Thesis work
* Major presentations
* Scholarship applications
* High-priority projects

# Key Learnings

### 1. Different Models Serve Different Purposes

Not every task requires the most powerful model. Choosing the appropriate model improves efficiency.

### 2. Claude Sonnet Is the Best Everyday Choice

For students, Sonnet provides the best balance between speed, reasoning, and resource usage.

### 3. Effort Settings Matter

Higher effort levels improve output quality but should be used only when necessary.

### 4. Context Improves Results

Providing clear instructions and relevant context produces more accurate and useful responses.

### 5. Iteration Produces Better Outputs

Using follow-up prompts often leads to significantly better results than relying on a single prompt.

### 6. Resource Management Is Important

Using advanced models only when needed helps maximize productivity and avoid unnecessary usage.

---

# Common Mistakes to Avoid

* Using Opus for every task
* Providing vague prompts
* Always selecting Max effort
* Submitting AI-generated drafts without review
* Not using follow-up prompts for refinement

---

# Conclusion

This exercise helped me understand how to use Claude more strategically. By selecting the right model, choosing the appropriate effort level, and providing detailed context, I can improve productivity, generate higher-quality outputs, and make better use of AI tools for learning, coding, research, and content creation.

### Main Takeaway

**The best AI strategy is not always using the most powerful model—it is using the right model for the right task.**
