# Day 39 – PDF Splitter & Merger

## 📌 Overview

As part of the 60 Days Claude AI Mastery Challenge, I built **PDF Splitter & Merger**, a browser-based document processing application that allows users to split, extract, preview, and merge PDF files directly in the browser.

The application is built as a single self-contained HTML file and performs all operations locally without relying on backend services or external servers.

---

## ✨ Features

### 📄 PDF Splitter

- Upload and preview PDF documents.
- Automatically detect the total number of pages.
- Generate visual page thumbnails.
- Split PDFs using custom page ranges.
- Split after specific pages.
- Split documents every N pages.
- Extract selected pages.
- Create multiple split operations in a single workflow.
- Validate page ranges and highlight invalid inputs.

### 📚 PDF Merger

- Upload multiple PDF files.
- Drag-and-drop support.
- Reorder files before merging.
- View page counts and estimated output size.
- Merge PDFs instantly.
- Download the generated document.
