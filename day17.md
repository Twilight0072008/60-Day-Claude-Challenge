# Day 17 – AI-Powered Vehicle Cost Analysis Dashboard

## Objective

The objective of this exercise was to use AI to transform vehicle information and fuel consumption data into an interactive HTML dashboard. The goal was to analyze fuel costs, compare Petrol and E85 fuel economics, calculate break-even points, and visualize key performance indicators through a modern dashboard.

---

# Task Overview

In this exercise, vehicle details and a CSV dataset were provided to Claude. Using a structured prompt, Claude generated a complete HTML-based dashboard that presented fuel cost analysis, maintenance insights, environmental impact, and interactive visualizations.

The dashboard was then reviewed in a web browser to analyze its functionality, design, and generated insights.

---

# Workflow

1. Gathered vehicle information.
2. Updated the prompt with vehicle details.
3. Uploaded the CSV dataset.
4. Generated the complete HTML dashboard using Claude.
5. Reviewed KPI cards and fuel comparisons.
6. Analyzed E85 economics and break-even calculations.
7. Explored SVG charts and visualizations.
8. Saved and opened the dashboard in a browser.
9. Captured screenshots of the final dashboard.

# Key Learnings

### 1. AI Can Generate Interactive Dashboards

Claude successfully transformed structured CSV data into a visually rich HTML dashboard with minimal manual effort.

---

### 2. Data Visualization Improves Understanding

Representing data through KPI cards and charts makes complex calculations easier to interpret.

---

### 3. Prompt Engineering Matters

A detailed prompt resulted in a more organized dashboard with better visual hierarchy and meaningful insights.

---

### 4. Economic Analysis Requires Multiple Factors

Fuel decisions should not be based solely on pump prices. Running cost, mileage, maintenance, and long-term expenses all influence the overall cost of ownership.

---

### 5. AI Accelerates Dashboard Development

Instead of manually building layouts and calculations, AI generated a functional prototype that can be further customized and enhanced.

---

# Conclusion

This exercise demonstrated how AI can combine data analysis, frontend development, and visualization to create an interactive decision-support dashboard. By integrating vehicle information with fuel consumption data, the dashboard provided meaningful insights into operating costs, break-even analysis, and environmental impact.

## Main Takeaway

**AI is evolving beyond content generation—it can build interactive applications that transform raw data into actionable insights, enabling faster analysis and better decision-making.**
