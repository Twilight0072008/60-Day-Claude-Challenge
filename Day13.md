# 🤖 AI Job Search Assistant

> Day 13 Project – Claude AI Challenge

An AI-powered Job Search Assistant designed to simplify the internship and job search process. The platform helps users discover relevant opportunities, analyze resumes, identify skill gaps, and receive personalized career recommendations through an intuitive dashboard.

This project demonstrates the concept of building an AI-driven career platform by combining modern UI design, intelligent workflows, and scalable full-stack architecture.
